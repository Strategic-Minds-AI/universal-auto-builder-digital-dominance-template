# Strategic Minds Universal Auto Builder + Digital Dominance

Private, branch-safe, reusable factory source kit. It combines real donor code with new validation and preview tooling. This is not a live mass-publishing service.

Extracted from Auto Builder:
- Dependency-free standalone HTML site renderer.
- 20 structurally different visual mini-layouts.

Extracted from Digital Dominance:
- 20 layout recipes, stripped of unsupported performance scores in the runtime catalog.

Run locally with Node 20+: npm test, npm run validate:demo, npm run preview:demo, npm run gallery.

The preview generator writes noindex, non-deployed static HTML and receipts. It does not create domains, run queues, send leads, start duplicate workers, or publish anything. A real X1/Vercel/Supabase adapter requires separately verified provider binding and approval.

Source and lineage: docs/SOURCE_MAP.md.
Integration and gates: docs/BRIDGE_CONTRACT.md and docs/RELEASE_GATES.md.
Template flag status must be verified in GitHub before calling this a native Template Repository.

Original donor projects and approved Website Launch Engine visuals are preserved, not redesigned or overwritten.
