# 16 worked implementation briefs

These are copy/paste-ready product briefs. They **do not execute integrations** and must follow evidence and approval gates.

Reusable steps: **PLAN -> DISCOVERY -> BRAND OPTIONS -> APPROVAL -> AUTO BUILDER DOCS -> BUILD -> VALIDATION -> RELEASE/OPERATE**.

Use the code in this repository only for SitePack schema checks, local synthetic previews and gallery until a specific provider adapter is installed and validated.
